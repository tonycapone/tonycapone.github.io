Privacy policy

Last updated: 12 November 2026

Hermes personal is a private assistant that Tony Howell runs on his own computer. Its only user is Tony.

What it accesses

Hermes personal asks Google for three read-only permissions on Tony's own account:

  • Gmail (gmail.readonly): read messages and settings.
  • Google Calendar (calendar.readonly): read calendars and events.
  • Google Drive (drive.readonly): find and read files, including Docs and Sheets.

It cannot send, create, change, share or delete anything.

How the data is used

Data is read only when Tony asks a question that needs it, and only to answer him. It is kept on Tony's own computer. It is not sold, shared with anyone else, or used for advertising.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
